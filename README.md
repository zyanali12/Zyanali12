I'm **Zyan Ali**, going by **zyanali12** — a full stack vibecoder. I build front to back: interfaces, APIs, databases, all of it. I code by feel as much as by logic, and I ship whatever I'm exploring on the tech side — web builds, course platforms, and full-stack experiments.
